# دليل بنية المدفوعات واشتراكات ماستركارد — MADRASI

## 1. القواعد والاشتراطات الأساسية
- **الطلبة وأولياء الأمور**: حسابات مجانية بشكل دائم مدى الحياة. لا توجد أي رسوم أو بوابات دفع لهم.
- **المدراء، المدرسون، المعلمون**:
  - فترة تجريبية مجانية لمدة 7 أيام عند التسجيل.
  - اشتراك شهري مدفوع بعد انتهاء التجربة (25,000 د.ع للمدير، 15,000 د.ع للمدرس/المعلم).
  - لكل حساب اشتراك مستقل خاص به.
- **طريقة الدفع الحصرية**: **بطاقة ماستركارد فقط** (Mastercard Only).
- **عند انتهاء الاشتراك**:
  - يتحول الحساب تلقائياً إلى وضع **القراءة فقط (Read-Only)**.
  - يتم تعطيل عمليات النشر، التعديل، رصد الدرجات، تسجيل الحضور، والعمليات الإدارية.
  - تبقى جميع البيانات السابقة والسنوات المؤرشفة آمنة ومتاحة للعرض.
  - تظهر رسالة وشريط تجديد واضح للمستخدم.

## 2. بنية بوابة الدفع في العراق (Mastercard Gateway Architecture)
نظراً لأن بطاقات ماستركارد الصادرة من المصارف العراقية (مثل Qi Card، مصرف بغداد، المصرف الأهلي العراقي، مصرف التنمية الدولي، زين كاش ماستركارد) تعمل وفق معايير البنك المركزي العراقي (CBI) والحماية ثلاثية الأبعاد (3-D Secure OTP):

```
┌─────────────────────────┐          ┌──────────────────────────┐          ┌─────────────────────────┐
│     MADRASI Mobile      │          │   Supabase Edge Function │          │   Mastercard Gateway    │
│      (Flutter App)      │          │     (create-checkout)    │          │      (MPGS / PSP)       │
└────────────┬────────────┘          └────────────┬─────────────┘          └────────────┬────────────┘
             │                                    │                                     │
             │ 1. طلب دفع (Plan ID + Promo)       │                                     │
             │───────────────────────────────────>│                                     │
             │                                    │ 2. إنشاء جلسة 3DS آمنة              │
             │                                    │────────────────────────────────────>│
             │                                    │ 3. إرجاع Checkout Session URL       │
             │                                    │<────────────────────────────────────│
             │ 4. فتح صفحة الدفع الآمنة           │                                     │
             │<───────────────────────────────────│                                     │
             │                                                                          │
             │ 5. إدخال رمز التحقق المصرفي (3-D Secure OTP) بواسطة حامل البطاقة          │
             │─────────────────────────────────────────────────────────────────────────>│
             │                                                                          │
             │                                    │ 6. Webhook إشعار الدفع الناجح       │
             │                                    │<────────────────────────────────────│
             │ 7. تفعيل الاشتراك في DataStore     │                                     │
             │<───────────────────────────────────│                                     │
```

### المتطلبات التشغيلية للتفعيل في الإنتاج:
1. التعاقد مع بوابة دفع مرخصة من البنك المركزي العراقي تدعم بطاقات ماستركارد بنظام MPGS (Mastercard Payment Gateway Services).
2. تعيين المتغيرات السرية في Supabase Edge Functions:
   - `PAYMENT_PROVIDER=MPGS_IRAQ`
   - `PAYMENT_MERCHANT_ID=...`
   - `PAYMENT_API_SECRET=...`
3. لا يتم تخزين أي بيانات للبطاقات إطلاقاً على خوادم مدرستي، ويُحفظ فقط الرمز التعريفي (Token) وآخر 4 أرقام للأغراض المحاسبية.
