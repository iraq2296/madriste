# مَدرَستي — MADRASI
> **"مدرستك أقرب، ومستقبلك أكبر"**
> المنصة التعليمية المتكاملة للمدارس العراقية.

تطبيق هاتف محمول متكامل (Android & iOS) مبني بأحدث معايير Flutter وRiverpod وMaterial 3، مع دعم كامل للغة العربية والاتجاه من اليمين لليسار (RTL)، واللغة الكردية والإنجليزية، والوضعين الفاتح والداكن، وعزل تام لبيانات كل مدرسة.

## 🚀 التشغيل السريع ومعاينة جميع الأدوار

التطبيق مزوّد بنظام **معاينة مدمج (Preview Mode)** يحتوي على قاعدة بيانات نموذجية واقعية لمدارس عراقية (بغداد، البصرة، نينوى)، تتيح تجربة جميع الحسابات والشاشات فوراً:

### 1. تشغيل التطبيق محلياً:
```bash
cd app
flutter run
```

### 2. الحسابات الجاهزة للتجربة الفورية في شاشة الدخول:
- **طالب**: أحمد علي عبد الله (`7703333331`)

- **معلّم إنكليزي**: م. حيدر عباس الساعدي (`7702222223`)

- **وليّ أمر**: علي عبد الله محمود (`7704444441`)
- **مالك التطبيق (Super Admin)**: مالك المنصة (`7700000001`)

## 🔒 الأمان وسياسات الامتثال
- **توثيق العلامة الزرقاء**: متاح فقط للمدارس، المدراء، والمدرسين والمعلمين. غير متاح للطلبة أو أولياء الأمور.
- **الحد الأقصى للأجهزة**: جهازان اثنان في الوقت نفسه لكل حساب، مع إمكانية إدارة الجلسات وتسجيل الخروج عن بُعد.
- **انتهاء الاشتراك**: تحويل الحساب للقراءة فقط (Read-Only) مع الحفاظ على البيانات ومنع النشر أو التعديل حتى التجديد.
- **حذف الحساب**: يقدم المستخدم طلب الحذف بنفسه مع تأكيد OTP، ويُعالج قانونياً دون وجود زر حذف مباشر بيد الإدارة.
- **التحقق من الوجه**: حد أقصى 3 محاولات فاشلة قبل التحويل للمراجعة اليدوية، مع إخلاء مسؤولية صريح بأنها مطابقة وليست إثباتاً حكومياً، وحذف شهري للمستندات المؤقتة.
